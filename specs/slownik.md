# Słownik pojęć

| Pojęcie | Definicja |
|---|---|
| Użytkownik | Osoba z kontem; może występować jako kierowca i jako pasażer. |
| Kierowca | Użytkownik publikujący przejazd swoim pojazdem. |
| Pasażer | Użytkownik rezerwujący miejsce w cudzym przejeździe. |
| Przejazd | Zaplanowana podróż kierowcy z trasą, datą, ceną i wolnymi miejscami. Statusy: Zaplanowany, W trakcie, Zakończony, Anulowany. |
| Przejazd cykliczny (seria) | Przejazd powtarzany w wybrane dni tygodnia; składa się z pojedynczych wystąpień. |
| Trasa | Linia na mapie od startu, przez przystanki, do celu. |
| Przystanek | Punkt pośredni na trasie, w którym kierowca może zabrać/wysadzić pasażera. |
| Rezerwacja | Prośba pasażera o miejsce w przejeździe. Statusy: Oczekująca, Potwierdzona, Odrzucona, Anulowana, Wygasła, Zrealizowana. |
| Dopasowanie „po drodze” | Sytuacja, w której punkty pasażera leżą blisko trasy kierowcy, choć nie są jej początkiem/końcem. |
| Koszt na miejsce | Część kosztów przejazdu przypadająca na jednego pasażera (dzielenie kosztów, nie zarobek). |
| Portfel | Konto wirtualnej waluty użytkownika służące do rozliczeń. |
| Punkty | Nagroda dla kierowcy za podwożenie, wymienialna na benefity miejskie. |
| Benefit miejski | Korzyść oferowana przez Urząd Miasta (np. bilet, parking) w zamian za punkty. |
| Ocena | Ocena 1–5 z opcjonalnym komentarzem wystawiana po zrealizowanym przejeździe. |
