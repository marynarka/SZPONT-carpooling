## Cel
Zapewnienie użytkownikom bezpiecznego konta i profilu, który buduje zaufanie. Jedno konto pozwala występować zarówno jako pasażer, jak i kierowca.

## Zakres
- rejestracja, logowanie, reset hasła
- profil użytkownika i jego widoczność
- pojazdy kierowcy
- weryfikacja konta
- administracja użytkownikami (panel web)
