## Cel
Pasażer szybko znajduje przejazd, który pasuje do jego trasy i godziny – także taki, w którym jego punkty leżą „po drodze” kierowcy.

## Zakres
- wyszukiwanie skąd/dokąd/kiedy
- lista wyników i szczegóły z mapą
- filtry i sortowanie
- dopasowanie „po drodze”
- lokalizacja użytkownika
- alerty o nowych przejazdach
